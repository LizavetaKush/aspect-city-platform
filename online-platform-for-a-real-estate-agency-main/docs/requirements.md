# Требования из документов

## Функции из DOCX

Приложение проектируется как онлайн-платформа агентства недвижимости "Аспект-сити" для Могилева.

Основные страницы:

- Лендинг-визитка агентства.
- Главная / дашборд.
- Каталог объектов.
- Мои объекты.
- Создание и редактирование объекта.
- Детали объекта и виртуальный тур.
- Профиль пользователя.
- Авторизация и регистрация.
- Административная панель.

Роли:

- Клиент: каталог, избранное, запись на просмотр, отслеживание заявок, рекомендации, интерактивная карта зон.
- Риелтор: создание и редактирование объектов, расширенные заметки, фото с изменением порядка, управление заявками, график статистики, фильтрация клиентов.
- Администратор: список пользователей, фильтрация, блокировка и разблокировка с причиной, просмотр деталей пользователя, read-only просмотр объектов.
- Администратор: аналитическая страница с KPI, графиками, диаграммами, воронкой и схемой связей платформы.
- Администратор: создание отчетов, предпросмотр, история сформированных отчетов, экспорт в Excel и PDF с корректной кириллицей.
- Клиенты и риелторы: двусторонний чат по объектам и заявкам на показы.

Общие функции:

- Фильтрация по типу, комнатам, цене, району, статусу.
- Сортировка по цене, площади, дате и популярности.
- Поиск по адресу и описанию.
- Избранное с сохранением в `localStorage`.
- Детальная карточка объекта с фото, картой, контактами риелтора и историей цены.
- Сохранение фильтров и сортировки после перезагрузки.
- Сброс настроек.
- Редактирование профиля, аватара и лицензии риелтора.

## Минимальные требования из PDF

- Не менее двух пользовательских ролей с принципиально разными функциями.
- Страницы авторизации и регистрации.
- Не менее 7 страниц кроме авторизации и регистрации.
- Не менее 15 функций приложения без учета авторизации и регистрации.
- Не менее 2 отчетов, доступных для скачивания.
- Не менее 20 разных компонентов интерфейса.
- Адаптивность от 1920/1440 px до 320 px без горизонтальной прокрутки.
- Интерактивные состояния элементов, hover/active/disabled и плавные анимации.
- Сохранение пользовательских параметров в `localStorage` и кнопка очистки.
- Не менее 8 связанных таблиц базы данных в третьей нормальной форме.
- RESTful API с базовой CRUD-структурой.
- Валидная и семантическая верстка.
- Обязательное использование React.
- Проверка работы в актуальном Google Chrome.

## Стек

- Frontend: React, Vite, CSS, lucide-react.
- Backend: Node.js, Express.
- База данных: PostgreSQL.
- ORM: Prisma.
- Контроль версий: GitHub.
